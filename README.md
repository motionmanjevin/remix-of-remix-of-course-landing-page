# Remix of Remix of Course Landing Page

Lovable Prompt — Rebuild High-Converting AI Course Website (Dark, Editorial, Conversion-First)

Start over and rebuild the website from scratch, using a dark, editorial, conversion-focused layout inspired by high-performing AI course landing pages.

The site should follow the same structural logic, section order, density, and hierarchy as the reference template:

Dark textured background

Strong headline with highlighted keyword

Persistent top navigation with pricing CTA

Urgency element (countdown)

Inline “AI input” style demo

Social proof near CTA

Video testimonial section below the fold

Do not copy assets or branding — recreate the layout and interaction patterns in an original design.

Visual Style & Theme

Dark graphite / charcoal background with subtle texture or grid

High contrast white typography

Single warm accent color (orange) for:

Highlighted headline words

Primary CTA buttons

Play button / key UI actions

No gradients, glass, or purple tones

Editorial, serious, confident tone — not playful

The design should feel:

Premium

Confident

“This course is worth the money”

Hero Section (Critical)

Recreate the hero section with the following structure:

Top navigation bar

Logo (left)

Nav links: Curriculum, Reviews, Pricing, Why us, FAQs

Primary CTA on the right:
“Enroll now for $499 →” (accent color)

Urgency strip

Countdown timer with copy like:
“Limited time offer ends in 17:35:25”

Compact, centered, high-contrast

Main headline

Large, bold, two-line headline

One keyword highlighted in accent color

Example structure (rewrite copy, keep structure):
“Master Prompt Engineering in 6 Weeks &
Supercharge your career.”

Interactive AI-style input demo

Looks like a prompt input box

Example placeholder:
“Rewrite this response to sound more confident and clear…”

This is a visual demo, not a real chatbot

Primary CTA

Button: Enroll now for $499

Accent color, strong contrast

Positioned directly under the demo

Social proof

Small avatar group + short credibility line

Example: “2k+ professionals already ahead of you”

Below the Fold

Large video section

Instructor speaking to camera

Centered play button in accent color

Clean framing, no decorative clutter

Video is a trust-builder, not a background element

Typography

Strong modern sans-serif

Large headline sizes

Tight hierarchy

No decorative fonts

Confident, senior-level tone

Responsiveness

Fully responsive across mobile, tablet, desktop

Sticky CTA preserved on mobile

Countdown, headline, and CTA remain visible without scrolling

No hover-only interactions

Functionality (Advanced Requirement)

Include at least one advanced component:

Countdown timer logic

Interactive demo input (UI-only is fine)

Sticky header with CTA

Video player component

Code must be:

Clean and readable

Editable inside Lovable

No hardcoded secrets or locked values

Accessibility & Performance

High contrast text

Clear focus states

Optimized images and video

No unused sections or drafts

Goal

Create a high-converting, serious, premium AI course landing page that:

Feels authoritative

Drives urgency

Makes the price feel justified

Looks like it converts at scale

Final note (important)

Do not “beautify” or “soften” this design.
Prioritize clarity, hierarchy, urgency, and trust over aesthetics.
